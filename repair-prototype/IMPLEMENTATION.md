# 损坏视频副本修复原型

目标：从原文件已丢失、传输或存储后损坏的视频副本中抢救可播放内容。

## 已实现

- 优先 MP4/MOV，先以 H.264 + AAC 样本验证。
- 输入只读；在健康磁盘创建工作副本，输出始终另存。
- 读取失败时停止普通修复，报告失败字节偏移，不使用零填充冒充完整副本。
- 诊断文件结构、媒体轨道和解码错误，区分缺失索引、文件截断和局部媒体数据损坏。
- 优先重新封装；失败时重新编码抢救；缺失索引时通过 Untrunc 使用健康参考片重建。
- 输出必须重新探测并完整解码检查，不能仅凭进程退出码或输出文件存在判定成功。
- 报告包含恢复时长、媒体轨道、验证错误和日志；原始时长未知时不计算恢复百分比。

## 验证样本

健康视频、尾部截断、索引损坏、媒体数据局部损坏、空文件、非视频文件、读取异常。

真实样本尚未提供；模拟损坏测试通过不代表真实文件必然可恢复。

## AI 与硬件适配

- Real-ESRGAN NCNN Vulkan 逐帧真实推理，6 帧一批，处理后清理临时图片并合成视频。
- 从 Vulkan API 检测实际显卡和设备编号，按设备类型和内存能力选择，不绑定品牌型号；支持手动选卡，分块默认按实际显存预算决定。
- 处理帧数与完整解码帧数必须相同；原音轨随后合并，较短音轨不截断处理完成的视频。
- AI 输出为平均帧率对应的恒定帧率，支持手机旋转规范化；HDR、时序 AI、人脸重建与 CPU 推理不在当前范围内。
- 安装来源及摘要、实际 GPU / 模型 / 分块、参考片验证与索引恢复结果写入报告。
